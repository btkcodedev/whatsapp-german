# CLAUDE.md — WhatsApp German Learning Bot

## Project Overview

This is a **WhatsApp-based German vocabulary learning system** with two components:

1. **Channel Bot** (`src/index.ts`) — Runs daily via GitHub Actions cron, posts "Word of the Day" to a WhatsApp Channel
2. **DM Bot** (`src/bot.ts`) — Persistent bot for 1-on-1 chats: onboarding, extra words, flashcards, level changes

**Stack**: TypeScript, Node.js, `whatsapp-web.js`, Google Gemini AI, SQLite, GitHub Actions

---

## Architecture

```
┌─────────────────────────────────────────────────────────────┐
│           GitHub Actions (free, no server needed)           │
│                                                             │
│   Cron: every day 8:00 AM IST                               │
│   ┌─────────────────────────────────────────────────────┐   │
│   │ 1. Restore WhatsApp session (from secret)           │   │
│   │ 2. Call Gemini → generate today's word              │   │
│   │    (level-aware, memory of past words, no repeats)  │   │
│   │ 3. Post to WhatsApp Channel                         │   │
│   │ 4. Commit progress.json back to repo                │   │
│   └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│         DM Bot (npm run bot — run locally or on Railway)    │
│                                                             │
│   When someone DMs your WhatsApp number:                    │
│   ├─ NEW user → asks: "What's your level? A1/A2/.../C2"     │
│   ├─ "more"      → extra word for their level (max 3/day)   │
│   ├─ "flashcard" → Gemini quiz on words they've learned     │
│   ├─ "level"     → change CEFR level                        │
│   └─ "help"      → show commands                            │
└─────────────────────────────────────────────────────────────┘
```

## Database Schema (SQLite)

```sql
-- Users: level, onboarding state, progress
CREATE TABLE users (
  phone_number    TEXT PRIMARY KEY,
  level           TEXT DEFAULT 'A1',
  state           TEXT DEFAULT 'NEW',          -- NEW | AWAITING_LEVEL | ACTIVE
  current_day     INTEGER DEFAULT 1,
  subscribed_at   DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- Word history per user (Gemini memory)
CREATE TABLE word_history (
  id              INTEGER PRIMARY KEY AUTOINCREMENT,
  phone_number    TEXT,
  day_number      INTEGER,
  german          TEXT,
  english         TEXT,
  topic           TEXT,
  level           TEXT,
  taught_at       DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- Daily extra-word counter (max 3/day)
CREATE TABLE daily_requests (
  phone_number    TEXT,
  request_date    TEXT,
  request_count   INTEGER DEFAULT 0,
  PRIMARY KEY (phone_number, request_date)
);

-- Flashcard attempts (spaced repetition)
CREATE TABLE flashcard_attempts (
  id              INTEGER PRIMARY KEY AUTOINCREMENT,
  phone_number    TEXT,
  german          TEXT,
  correct         INTEGER,                     -- 1=correct, 0=wrong
  attempted_at    DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

## CEFR Levels & Topics

Defined in `src/vocabulary.ts:TOPICS`:

- **A1** (20 topics): Greetings, Numbers, Colors, Family, Food, etc.
- **A2** (20 topics): Daily Routines, Past Tense, Travel, Modal Verbs, etc.
- **B1** (14 topics): Opinions, Subjunctive, Passive, Relative Clauses, etc.
- **B2** (11 topics): Formal Writing, Idioms, Economy, Advanced Konjunktiv, etc.
- **C1** (11 topics): Academic Register, Nominalization, Literature, Law, etc.
- **C2** (7 topics): Archaic Language, Rare Idioms, Rhetoric, etc.

Each day cycles through topics for the user's level.

---

## Word Generation Flow (Gemini)

1. **Input**: day number, CEFR level, word history (last 40 words)
2. **Prompt**: Structured JSON schema + memory block of past words
3. **Output**: `WordOfTheDay` object with german, article, partOfSpeech, english, pronunciation, example, memoryTip, topic
4. **Deduplication**: Gemini instructed not to repeat words from history

## Flashcard System

- **Trigger**: User sends "flashcard"
- **Selection**: Picks weak words (wrong answers) or random from history
- **Format**: Multiple choice or translation question
- **Tracking**: Results saved to `flashcard_attempts` for spaced repetition

## Deployment

### GitHub Actions (Channel Bot)

Workflow: `.github/workflows/daily-word.yml`
- Runs daily at 8:00 AM IST
- Restores `WWEBJS_AUTH` secret → `.wwebjs_auth`
- Runs `npm run start`
- Commits updated `data/progress.json`

### DM Bot Hosting Options

1. **Local**: `npm run bot` (keep terminal open)
2. **Railway/Render/Fly.io**: Persistent Node.js process
3. **VPS**: PM2 + `npm run bot`

## Development Notes

- **WhatsApp Session**: Stored in `.wwebjs_auth/` (gitignored). Generated once via `npm run setup`.
- **TypeScript**: Strict mode, CommonJS output, source maps enabled.
- **Error Handling**: Both bots destroy client on auth failure or posting error.
- **Rate Limits**: Channel posts once/day. DM bot: 3 extra words/day per user.

## Common Tasks

### Add a new CEFR level topic
Edit `src/vocabulary.ts:TOPICS` object.

### Modify word generation prompt
Edit `src/vocabulary.ts:generateWord()` prompt template.

### Add a new DM command
1. Add handler in `src/bot.ts` message listener
2. Add help text in `help` command response

### Debug Gemini output
Set `GEMINI_API_KEY` locally, run `npm run start` — check console for generated word JSON.

### Reset user progress
Delete `data/progress.json` (channel) or clear SQLite `users`/`word_history` tables (DM bot).

## Troubleshooting

| Issue | Fix |
|-------|-----|
| "CHANNEL_ID not set" | Add Channel invite code to GitHub Secrets / `.env` |
| "GEMINI_API_KEY not set" | Add API key to GitHub Secrets / `.env` |
| QR code not scanning | Run `npm run setup` locally with `headless: false` |
| Session expired | Re-run `npm run setup`, update `WWEBJS_AUTH` secret |
| "Auth failure" | Delete `.wwebjs_auth/`, re-run setup |
| Database locked | Ensure only one bot instance runs at a time |

## Security Notes

- **Never commit** `.wwebjs_auth/`, `.env`, or `WWEBJS_AUTH` secret
- Use **dedicated WhatsApp number** (not personal)
- Gemini API key has generous free tier
- SQLite database is local file (`data/database.sqlite`)
